    Before you export

    Review these tips for cleaner, more precise HTML & CSS output.

    • Use Auto Layout on frames (and nested frames). Flex/grid mapping is most accurate when layout is not “None”.
    • Use real image assets for photos, illustrations, and icons. Prefer IMAGE fills or vectors—not nested frames/groups that only look like images. Sites usually ship fixed assets, not deep layout trees for every graphic.
    • Flatten decorative shapes when possible (boolean ops / vectors). Complex nested groups export less cleanly than a single SVG or PNG.
    • Name layers clearly (e.g. hero-image, icon-arrow). Names become CSS classes and asset filenames in the ZIP.
    • Enable Clip content on frames that should mask overflow (rounded cards, image crops). This maps to CSS overflow / clip-path.
    • Select one root frame with auto layout or grid. Export one composition at a time for the best structure.
